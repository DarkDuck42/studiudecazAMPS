CERCETARE: De ce Git & GitHub?

În procesul de dezvoltare software modern, lucrul colaborativ necesită un flux organizat pentru a asigura integritatea codului sursă:

  • Branching & Merging: Permite dezvoltarea simultană de funcționalități pe ramuri izolate fără a strica versiunea de producție.
  • Istoric Integrat: Fiecare modificare este salvată cu un mesaj explicit, autor și posibilitate de rollback instant.
  • Code Review: Prin intermediul Pull Request-urilor, codul este verificat de colegi înainte de integrarea finală.

Comenzile GitBash Utilizate

bash — studiu-de-caz
# 1. Inițializarea repozitoriului local
git init

# 2. Adăugarea fișierelor pregătite
git add index.html main.css

# 3. Crearea primului commit
git commit -m "feat: adaugat index.html si main.css pentru studiu de caz"

# 4. Setarea ramurii principale
git branch -M main

# 5. Legarea de repozitoriul remote de pe GitHub
git remote add origin https://github.com/UTILIZATOR/studiu-de-caz.git

# 6. Push-ul codului pe GitHub
git push -u origin main

Găzduire & Colaborare

1. Configurare GitHub Pages: Navigați la Settings > Pages, selectați ramura main și activați găzduirea gratuită.

2. Invitații Colaboratori: Accesați Settings > Collaborators, apăsați pe "Add people" și adăugați colegii de echipă.
